# 🤖 AI-ассистент ProtoLab 3D

Полноценная система AI-консультанта для сайта студии 3D-печати с интеграцией DeepSeek API и RAG-поиском по базе знаний.

## 📦 Что включено

### 1. **system_prompt.md** (`/public/system_prompt.md`)
Системный промпт для DeepSeek с:
- Ролью ассистента
- Жёсткими правилами (не выдумывать, передавать менеджеру при неуверенности)
- Стилем общения (русский, "вы", 2-6 предложений, вопрос в конце)
- Формулами расчёта стоимости
- Самопроверкой перед ответом

### 2. **knowledge_base.json** (`/public/knowledge_base.json`)
Структурированная база знаний:
- Информация о компании (адрес, контакты)
- Технологии (FDM, SLA, SLS, DMLS)
- Материалы (PLA, PETG, ABS, TPU, нейлон, карбон) с ценами и характеристиками
- Принтеры (6 штук) с характеристиками
- Услуги и цены
- Постобработка
- Доставка
- Скидки и доплаты
- Ограничения

### 3. **faq.json** (`/public/faq.json`)
100 пар вопрос-ответ в 7 категориях:
1. Технологии и возможности (15 вопросов)
2. Материалы (20 вопросов)
3. Цены и расчёт (20 вопросов)
4. Сроки (15 вопросов)
5. Постобработка (15 вопросов)
6. Файлы (10 вопросов)
7. Доставка и логистика (5 вопросов)

### 4. **Код интеграции**
- `src/deepseek.ts` — интеграция с DeepSeek API + RAG-поиск
- `src/ChatBot.tsx` — виджет чата с гибридной логикой
- `src/knowledgeBase.ts` — локальная база знаний для быстрого поиска

## 🚀 Как работает

### Гибридная система ответов:

1. **Сначала локальная база знаний** (быстро, бесплатно)
   - Поиск по ключевым словам в `knowledgeBase.ts`
   - Мгновенный ответ без API

2. **Если не нашёл → DeepSeek API** (умно, с контекстом)
   - RAG-поиск по `knowledge_base.json` и `faq.json`
   - Передача контекста + истории разговора в DeepSeek
   - Температура 0.3 для точности

3. **Если DeepSeek не знает → передача менеджеру**
   - Предложение оставить заявку
   - Кнопка "Связаться с менеджером" → открывает Telegram

## 🔑 Настройка DeepSeek API

### Шаг 1: Получите API ключ
1. Зайдите на https://platform.deepseek.com/api_keys
2. Зарегистрируйтесь (если нужно)
3. Создайте API ключ
4. Скопируйте ключ (начинается с `sk-`)

### Шаг 2: Введите ключ в боте
1. Откройте чат-бот на сайте
2. Нажмите на иконку настроек ⚙️ в заголовке
3. Вставьте API ключ
4. Нажмите "Сохранить"

Ключ хранится **только в вашем браузере** (localStorage) и не передаётся на сервер.

## 📊 Что нужно заполнить

В `knowledge_base.json` есть поля с `{{TODO_ЗАПОЛНИТЬ}}`:

### Обязательные поля:
- `company.phone` — телефон компании
- `company.email` — email компании
- `technologies[1-3].max_size` — размеры для SLA/SLS/DMLS
- `services[2-3].price` — цены на сканирование и реверс-инжиниринг
- `delivery.shipping.international` — международная доставка

### Опциональные поля:
- Уточните характеристики партнёрских технологий (SLA, SLS, DMLS)
- Добавьте больше материалов при необходимости

## 💡 Быстрые кнопки

В чате есть 4 быстрые кнопки:
- 💰 **Рассчитать стоимость** — расчёт по формуле
- 🧪 **Выбрать материал** — помощь в выборе
- ⏱ **Сроки** — информация о сроках
- 👨‍💼 **Связаться с менеджером** — открывает Telegram

## 🔒 Безопасность

- ✅ API ключ хранится только в localStorage пользователя
- ✅ Не передаётся на ваш сервер
- ✅ Не виден другим пользователям
- ✅ Можно удалить в любой момент
- ✅ DeepSeek вызывается напрямую из браузера

## 🛠 Технологии

- **Фронтенд**: React + TypeScript + Tailwind CSS
- **AI**: DeepSeek API (deepseek-chat модель)
- **RAG**: Keyword-поиск по JSON базам
- **Хранение**: localStorage для API ключа
- **Сборка**: Vite
