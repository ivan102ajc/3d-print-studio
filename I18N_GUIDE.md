# 🌍 Мультиязычность - Руководство

Сайт ProtoLab 3D теперь поддерживает три языка: **Русский**, **English** и **中文** (китайский).

## 📋 Что переведено

### Полностью переведены:
- ✅ Навигация (все пункты меню)
- ✅ Главная секция (Hero)
- ✅ О нас
- ✅ Услуги
- ✅ Оборудование
- ✅ Материалы
- ✅ Калькулятор стоимости
- ✅ Галерея работ
- ✅ MakerWorld инструменты
- ✅ Контакты
- ✅ Футер
- ✅ Переключатель темы

### Не переводятся:
- ❌ Названия материалов (PLA, PETG, ABS и т.д.) - это международные обозначения
- ❌ Названия принтеров (Bambu Lab, Creality и т.д.) - это бренды
- ❌ Цены в рублях (₽) - можно добавить конвертацию при необходимости
- ❌ Изображения в галерее - можно добавить подписи на разных языках

## 🎮 Как переключать язык

### На десктопе:
В навигации есть кнопка с флагом и кодом текущего языка:
- Нажмите на кнопку (🇷🇺 RU / 🇬🇧 EN / 🇨🇳 中文)
- Откроется dropdown с тремя языками
- Выберите нужный язык
- Dropdown закроется автоматически

### На мобильных устройствах:
Кнопка языка находится в верхней панели рядом с переключателем темы:
- Нажмите на флаг текущего языка
- Откроется dropdown с тремя языками
- Выберите нужный язык
- Dropdown закроется автоматически

### Закрытие dropdown:
- Клик вне dropdown автоматически закрывает его
- Выбор языка автоматически закрывает dropdown

### Шаг 1: Добавьте переводы в `src/i18n.ts`


## 🌐 Особенности перевода

### Русский (ru)
- Язык по умолчанию
- Полные переводы всех элементов
- Форматирование чисел: `1 234 ₽`

### Английский (en)
- Международная версия
- Адаптированные формулировки
- Форматирование чисел: `1,234 ₽`

### Китайский (zh)
- Упрощённый китайский
- Адаптированные формулировки
- Форматирование чисел: `1,234 ₽`

## 💡 Советы по переводу

### 1. Контекст важен
Переводите с учётом контекста 3D-печати:
- "Печать" → "Printing" / "打印"
- "Модель" → "Model" / "模型"
- "Материал" → "Material" / "材料"

### 2. Технические термины
Некоторые термины лучше оставлять на английском:
- FDM, PLA, PETG, ABS, TPU
- STL, 3MF, OBJ
- G-code

### 3. Единицы измерения
- мм → mm → 毫米
- г → g → 克
- ₽ → ₽ → ₽ (можно добавить CNY/USD)

### 4. Форматирование
- Русские числа: `1 234` (пробел как разделитель)
- Английские числа: `1,234` (запятая как разделитель)
- Китайские числа: `1,234` (запятая как разделитель)

## 🐛 Решение проблем

### Проблема: Текст не переводится
**Решение:** Проверьте, что ключ есть во всех трёх языках в `i18n.ts`

### Проблема: Переключатель не работает
**Решение:** Проверьте консоль браузера на ошибки JavaScript

### Проблема: Некоторые элементы на русском
**Решение:** Добавьте переводы для этих элементов в `i18n.ts`
